Sean Toolbox 个人工具箱，提供应用窗口快捷键、Quake 停靠和 VS Code 最近项目搜索。

请下载与系统和处理器匹配的压缩包，完整解压后查看其中的 `INSTALL.md`。
主程序与界面程序放在同一目录；macOS 保持整个 `.app` 完整。
默认按 `Ctrl+Alt+Space` 打开最近项目面板，也可从托盘打开应用配置和设置。

每份归档旁提供 `.sha256` 校验文件。当前 Windows 包未做 Authenticode 签名；
macOS 包未做 Developer ID 签名及 Apple 公证。

平台支持和使用方法见 [项目说明](https://github.com/sean2077/sean-toolbox#readme)。
